# Social Benchmark design

Mode: Operate / Read. Researchers compare exact model experiences and inspect supporting conversations. The first viewport must expose real evidence counts, filters, candidate-label distributions, and publication limits. No marketing claims or fabricated scores.

Direction: quiet research ledger. Light mineral-grey surfaces, dark green-black text, muted green for positive candidate labels and brick for negative labels. Color encodes data. One Segoe UI family, fixed type scale, tabular figures, aligned tables, 224px neutral navigation. Compact title, real source coverage and 1,000-chunk collection progress beside the table. Mobile changes to top navigation and stacked panels.

Signature interaction: exclude vendor-focused sources and immediately inspect the changed underlying sample; drill from a model row into source-linked claim excerpts. No animated entrances or decorative charts. Keyboard focus and immediate filter updates take priority.

Guidance loaded from Emil Kowalski design engineering, Impeccable (Operate mode), and Taste (app screens). Upstream instruction snapshots are in design-references. Context launcher and full browser inspector were unavailable; do not claim their checks passed.


Visitor-first update: Arena.ai leaderboard used as a product reference (https://arena.ai/leaderboard, inspected 2026-10-30), without importing its scores or branding. Default shell is now compact top navigation. Use-case buttons lead the flow; specific versions are shown by default. Advanced filters are collapsed. Compare offers two model selectors with category-specific praise, concerns, thread counts, and source links. Collection goals live on Sources. The labeling workspace loads only on demand. No unsupported numerical leaderboard is manufactured.
